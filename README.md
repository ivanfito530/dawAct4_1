### Branch
_Funcion_
Code `git branch`
La funcion de este codigo seria mostrar las ramas que tienes creadas y disponibles

### Merge
_Funcion_
Code `git merge rama`
La funcion de esta linea de codigo seria fusionar la rama que pongamos en dicha funcion para fusionarla con la que estemos actualmente
